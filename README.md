# Subdomain providers

A curated list of subdomain provider domains.

## List

The `names` file contains one entry per line in format `registered_domain_name, service_type`. 

We define the following service types:

- csp: Cloud Service Provider
- ddns: Dynamic DNS Provider
- fpp: Free Page Provider
- fsp: Free Subdomain Provider
- fss: File Sharing Service
- ipfs: InterPlanetary File System
- lrs: Link redirection service
- psp: Paid Subdomain Provider
- tss: Text Sharing Service

Use this link to fetch the latest version of the list: [https://raw.githubusercontent.com/korlabsio/subdomain_providers/refs/heads/main/names](https://raw.githubusercontent.com/korlabsio/subdomain_providers/refs/heads/main/names).
